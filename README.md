# Jornada de Aprendizado em C

Este repositório foi criado para documentar minha evolução no aprendizado da linguagem de programação C, reunindo projetos práticos desenvolvidos ao longo dos meus estudos.

O objetivo é aplicar progressivamente os conceitos aprendidos, aprimorar minha lógica de programação e desenvolver uma base sólida para projetos mais complexos.

## Objetivos

- Consolidar os fundamentos da linguagem C.
- Aprimorar a lógica de programação e a resolução de problemas.
- Praticar a organização e modularização de código.
- Desenvolver conhecimentos sobre ponteiros e gerenciamento de memória.
- Aplicar boas práticas de programação e segurança de software.
- Acompanhar minha evolução por meio de projetos e commits.

## Organização do Repositório

Cada projeto possui seu próprio diretório, contendo o código-fonte e, quando necessário, um README com informações sobre seu funcionamento, conceitos aplicados e limitações.

Os projetos são numerados para facilitar a organização e o acompanhamento da evolução.

## Observações

Este é um repositório educacional. Os projetos representam diferentes etapas do meu aprendizado e podem apresentar limitações, implementações simplificadas ou funcionalidades ainda em desenvolvimento.

Melhorias e refatorações serão registradas ao longo do tempo por meio do histórico de commits.
